# AutoLog Images

This directory contains image assets for the AutoLog app.

## Planned Assets

- `logo.png` — AutoLog app logo (used on splash screen)
- `logo_dark.png` — AutoLog app logo for dark backgrounds
- `onboarding_1.png` — Onboarding slide 1: Manage all vehicles
- `onboarding_2.png` — Onboarding slide 2: Track expenses
- `onboarding_3.png` — Onboarding slide 3: Never miss service dates
- `empty_vehicles.png` — Empty state illustration for vehicles list
- `empty_logs.png` — Empty state illustration for logs list
- `empty_analytics.png` — Empty state illustration for analytics

## Notes

- All images should be provided in 1x, 2x, and 3x resolutions.
- Use PNG format for illustrations and logos.
- Target dimensions: 300×300 px at 1x for illustrations.
